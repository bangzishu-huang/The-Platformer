# The-Platformer
A simple game where your primary goal is to shoot and eliminate targets while navigating through a variety of platforms.

I was looking to create a game with very clean graphics, simple mechanism, but still had a very intriguing gameplay part. This is where I came up with the idea of creating one of those platformer games, where the user would have to walk and jump around platforms, avoiding obstacles and trying to eliminate the bad guys. I really love how the entire game came out as well as the simple but aesthetic graphics that were given.

The entire experience taught me a lot about general code debugging because there were so many times where I either coded a letter wrong or I was just completely lost. By pushing through all the challenges that were presented to me, I was able to say I finally successfully finished this game. I also learned a lot of new additional python techniques that I would be sure to continue to incorporate within my time doing game development. This was just an overall amazing learning experience, and all the late nights trying to find out the solution to a bug allowed me to rapidly grow in my understanding of python.

Controls: Arrow keys to move around and jump, space to shoot

AI Used: None

# Tech Slack
- Frontend: Python
- Hosting: GitHub Pages
- Version Control: GitHub
- Development Tools: Visual Studio Code, Pygame-CE, Pygbag

# Features
- A series of different difficulties you can try, split into 4 unique levels 
- Multiplier numbers are shown on your screen dependent upon your elimination number
- Abilities can be gain after every 5 kills and there is a carousel animation in order to display that
- The whole game is incorporated with sound effects, and background music
- The worms and bees, who are your enemies move in very different ways in order to make the game feel harder
